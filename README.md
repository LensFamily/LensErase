# LensErase

**A Foundation Model for Erase Anything**

Project website: [lensfamily.github.io/LensErase](https://lensfamily.github.io/LensErase/)

The website includes animated removal examples, qualitative comparisons, an overview of LensErase-100M and LensErase-Bench, and image-source credits.

## Website

The static website is maintained in `docs/`. The `gh-pages` branch contains the published site at its root. In GitHub Pages settings, select **Deploy from a branch**, **gh-pages**, and **/ (root)**.

For a local preview:

```bash
python -m http.server 8765 --directory docs
```

Open <http://localhost:8765/>. No build step is required.

Code and paper links will be added when released. Image-source credits are provided in the website's image previews and Image Credits section.
